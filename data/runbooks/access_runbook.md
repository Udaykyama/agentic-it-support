# Access Issues Runbook

**Problem:** Users are experiencing issues related to access, including permission denials, password resets, and account lockouts.

**Root Cause:** Common access issues stem from password management errors, lockout due to multiple failed attempts, or insufficient permissions for shared resources.

**Steps:**
1. For shared drive access issues, verify user permissions and ensure the correct share path is being used. 2. For forgotten passwords, verify the user's identity and send a password reset link to their registered email. 3. If an account is locked out, reset the account status and ensure the user can log in again. 4. For expired passwords, instruct the user to follow the password reset link and update their password. 5. For locked accounts due to expired passwords, reset the user's password and unlock the account. 6. Document the incident and communicate with the user to confirm access restoration.

**Prevention:** Implement regular password expiration reminders and user training on password management to minimize access issues.
